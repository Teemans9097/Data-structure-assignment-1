# Stack-Based Expression Calculator

## Overview
This Python program reads mathematical expressions from input.txt,
evaluates them using stacks, and writes the results to output.txt.

## Requirements
- Python 3
- No external packages are required.

## Project Files
- calculator.py: Stack class, expression evaluator, and file processing.
- input.txt: Mathematical expressions used as input.
- output.txt: Results generated by the program.
- README.md: Instructions and program documentation.

## How to Run
Place input.txt beside calculator.py.
Open a terminal in the project folder and run:

```bash
python calculator.py
```

The program creates or overwrites output.txt in the same folder.

## Input Format
Write one expression per line.
Separate expressions with lines containing two or more hyphens.
Blank lines are also allowed.

Example:

```text
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## Output Format
Each expression is replaced by its result.
Separator lines and blank lines are preserved.

Expected output for the example:

```text
13
-----
16
-----
-10
```

Note: The assignment brief shows 17 for the second expression.
The mathematically correct result is 16.

## Stack Implementation
The Stack class uses a Python list and provides:
- push(item): Add an item to the top.
- pop(): Remove and return the top item.
- peek(): Return the top item without removing it.
- is_empty(): Check whether the stack is empty.

Popping or peeking at an empty stack raises IndexError.

## Expression Evaluation
The evaluator uses two stacks:
- A numbers stack for operands and intermediate results.
- An operators stack for operators and opening parentheses.

Multiplication and division have higher precedence than addition
and subtraction. Operators with equal precedence are evaluated
from left to right. Parentheses override normal precedence.

The program evaluates expressions without using eval().

## Error Handling
Invalid expressions produce an Error message in output.txt.
The line number and error are also displayed in the terminal.
Processing continues with the remaining expressions.

Errors include:
- Division by zero.
- Unmatched parentheses.
- Missing operands or operators.
- Unsupported characters.

If input.txt is missing, the program displays a message.

## Testing
Testing covers:
- Stack operations and empty-stack errors.
- Operator precedence.
- Left-to-right evaluation.
- Nested parentheses.
- Decimal calculations.
- Negative results.
- Division by zero and invalid expressions.

Sample verified results:
- 3 + 5 * 2 = 13
- 20 / 5 * 2 = 8
- 10 - 3 - 2 = 5
- 2 * (3 + (4 * 5)) = 46
- 2.5 * 4 + 1 = 11
- 10 / 4 = 2.5

## Assumptions and Limitations
- Supported operators are +, -, *, and /.
- Whole numbers and decimals such as 2.5 are supported.
- Unary signs such as -5 or +3 are not supported.
  Use (0 - 5) to express a negative input.
- Decimal numbers must have digits before and after the decimal point.
- Implicit multiplication such as 2(3 + 4) is not supported.
  Write 2 * (3 + 4) instead.
- Powers, variables, functions, and scientific notation are not supported.
- Whitespace is removed before parsing; spaces must not be used
  to separate digits that should represent different numbers.
- Decimal calculations use Python floating-point arithmetic,
  which can introduce small rounding differences.
